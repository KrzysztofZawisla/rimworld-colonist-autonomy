# Colonist Autonomy — Workshop visual language

## Field ledger

The set borrows its structure from the colony work tab: ruled paper, ink hairlines, and a grid of
priorities. One cell is filled rust. That cell is the model's choice, and the rest of the grid
shows the closed list the game prepared. The motif repeats at every scale, from the square
preview to the cover, so the mod is recognizable before anyone reads a word.

Surfaces are paper, not screens. The background is a greenish grey paper tone, panels are a
lighter sheet, and every edge is a single ink rule. Nothing has a shadow, a gradient, or a
rounded corner. The only filled block in a composition is the one that carries a decision, a
default, or a recommendation. That restraint makes rust mean something.

Type behaves like a printed form. Bahnschrift sets the display lines in title case; Segoe UI
carries explanations and labels; Consolas appears only for values that are data, never for
decoration. Labels are sentence case. Numerals appear only where the content is a real sequence,
as in the four-step pipeline. Elsewhere the layout carries the order.

Space is measured, not decorated. Margins are constant, rules align across pages, and every text
frame is sized to its content. Arrows are drawn as geometry or omitted; nothing relies on a
glyph from a fallback font. The work is checked at 100 percent and at thumbnail size, because a
Workshop image has to read in a list before it is opened.

The palette is deliberately narrow: paper, ink, graphite, rust, olive. Rust marks the chosen
option and the recommended model. Olive marks the alternative. Paper and ink do everything else.
Every alignment and every one-pixel rule was refined by hand; the result should look like a
printed field sheet, not a generated tech poster.
