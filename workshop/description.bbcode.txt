[h1]Colonist Autonomy[/h1]
[b]A local decision model for what your colonists do next.[/b]

Colonist Autonomy gives idle colonists a second opinion. When vanilla RimWorld has no job for a colonist, the mod builds a closed list of actions the game can actually perform, asks a local model to rank them, and turns the winner into a normal RimWorld job. The model never writes text, and your colony data stays on your machine.

[h2]How it works[/h2]
[list]
[*][b]Collect.[/b] The game prepares every job a colonist could take and a compact colony state.
[*][b]Rank.[/b] One request goes to a local llama-server. The model scores the closed list.
[*][b]Choose.[/b] The best option returns with a confidence value.
[*][b]Apply.[/b] The mod issues a vanilla job. Below the confidence threshold, vanilla keeps control.
[/list]

[h2]Decision modes[/h2]
[list]
[*][b]Intent.[/b] The model picks the goal. The game picks the exact target.
[*][b]Action (default).[/b] The model picks the job and its target. Needs still use the game's target.
[*][b]Intent and target.[/b] The model answers twice in one request: intent first, then the target inside it.
[*][b]Hybrid (auto).[/b] Uses Intent when no concrete target exists and Action when one does.
[/list]

[h2]Models[/h2]
The installer can fetch llama.cpp and one model on Windows x64, Linux x64 and macOS.
[list]
[*][b]Clef Flash Q8 (recommended).[/b] 9B, 9.7 GB download, about 16 GB VRAM at 16k context. Fast and light.
[*][b]Clef Q4 (optional).[/b] 27B, 17.6 GB download, 24 GB or more VRAM. Higher quality, slower.
[/list]
[img]PASTE_URL_FOR_MODELS_IMAGE[/img]
The server runs locally. You can point the mod at another llama-server model that supports `/v1/systemone`; Clef is the model the installer ships.

[h2]Requirements[/h2]
[list]
[*]RimWorld 1.7 with Harmony.
[*]Windows x64 or Linux x64 with a working Vulkan driver, or macOS (Intel or Apple Silicon).
[*]A GPU with enough VRAM for the model you choose. CPU-only inference is not installed.
[*]Disk space for the model plus the llama.cpp archive.
[/list]

[h2]First start[/h2]
[list]
[*]Subscribe to Harmony.
[*]Open [b]Options > Mod settings > Colonist Autonomy[/b].
[*]Click [b]Install / check dependencies[/b]. This installs llama.cpp and the recommended Flash model.
[*]Wait for the download. A cancelled download resumes from the .part file.
[*]Enable [b]Auto-start llama-server[/b] in the mod settings after reviewing the paths.
[*]Start or load a colony. The local server starts when the colony loads and stops when you leave the game.
[/list]

[h2]Notes[/h2]
[list]
[*]Decisions are made locally. Colony data is sent only to your local server.
[*]The mod runs HTTP on a worker thread, so the game does not wait for the model.
[*]Low confidence hands the decision back to vanilla.
[*]Auto-start is off by default. Auto-start and auto-stop use Harmony game events. Without Harmony, the settings still open.
[/list]
